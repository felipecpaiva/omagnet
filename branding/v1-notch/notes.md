A pixel horseshoe magnet pulls one window up toward its pale pole tips, inside a quiet chamfered frame.
Narrow legs, a wide open gap and contrasting tips make it read as a magnet, and the grid makes the snap feel exact.
Palette: charcoal-blue background #12141a; amber magnet #ff9f1c; cream window title #fff1d6; lilac pole tips #e8e6ff; slate window #8d97ab; graphite frame #252b36.
Wordmark: hand-built pixel letters (no font needed). If a font is wanted, JetBrains Mono (open source, Omarchy's own default).
Unlike Magnet: no blue, no rounded tile, no window mosaic. Unlike Omarchy: amber instead of green, and a magnet instead of a bare frame.
Process note: Codex's first picture (codex-concept.png) read as a beer mug, so the final icon was redrawn by hand on an exact 16 by 16 grid.
