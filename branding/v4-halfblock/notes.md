A chunky pixel "o" followed by a terminal cursor block: the name, typed at a prompt.
It is the whole idea in one glyph: lowercase, terminal-native, and the cursor is the "snap" that lands next to it.
Palette: near-black ground #0b0d10; phosphor mint #5ef2c1; hot coral cursor #ff6b6b.
Wordmark: hand-built pixel letters with the same coral cursor block after them (no font needed). If a font is wanted, JetBrains Mono.
Unlike Magnet: no blue, no tiles, no window mosaic. Unlike Omarchy: mint and coral instead of green, and the cursor block is its own idea, not a frame or a wordmark.
Process note: Codex's first picture (codex-concept.png) read like a webcam, so the final icon was redrawn by hand on a 16 by 16 grid.
